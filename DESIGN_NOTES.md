# Visual direction

PROCELYX explains how real work moves through a company. Its main visual is a legible process, accompanied by the founder's supplied portrait.

- Palette: ink #0b0f14, slate #14212b, paper #edf4fb, muted steel #a7bacb, teal #69e0cf, amber #e7bc79 for human checkpoints.
- Type: system Segoe UI for dependable Czech rendering, bold compact headings, readable body copy. No remote font request.
- Layout: left-aligned editorial headings; process diagram beside the opening statement; three chronological pilot steps; alternating process illustrations and text; a quiet, uncropped portrait.
- Infographics explain article-specific inputs, handovers and outputs. No invented results, client logos or screenshots.
- Existing dark/teal direction comes from the owner's brief. Remove unnecessary numbering on service cards, fake window chrome and inert demo controls. Use numbered stages only for a real sequence.
- Review: preserve the recognizable identity, reduce decorative gradients, add meaningful diagram illustrations and give the portrait natural proportions on mobile.
