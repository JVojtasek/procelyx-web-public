# PROCELYX web

Zdrojový kód veřejného webu [procelyx.cz](https://procelyx.cz) — AI automatizace a digitální procesy pro firmy.

- Cloudflare Worker + statická aktiva (`public/`), kontaktní formulář v `src/`.
- Sestavení: `npm ci && npm run build && npm test && npm run check`.
- Správa a provoz: [`ADMIN_RUNBOOK.md`](ADMIN_RUNBOOK.md), pravidla pro vývoj: [`CLAUDE.md`](CLAUDE.md).

Texty, fotografie a grafika jsou obsahem webu PROCELYX a nejsou určené k dalšímu šíření. Kód je zveřejněný pro transparentnost.
