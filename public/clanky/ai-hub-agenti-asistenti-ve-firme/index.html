AI Hub ve firmě: proč jeden chatbot nestačí

Samostatný chatbot umí odpovědět. Firemní AI Hub má rozumět kontextu, pracovat s nástroji a předávat práci mezi specializovanými agenty.

Anonymizovaný use case23. 9. 2026Jaroslav Vojtášek

První kontakt firem s generativní AI bývá chatbot. To je užitečný začátek, ale rychle narazí na limit: odpověď sama o sobě proces nedokončí. Firma potřebuje zapsat lead do CRM, vytvořit úkol, najít dokument, připravit podklady, hlídat termín a později informovat zákazníka.

Co znamená AI Hub

AI Hub je společná vrstva, která propojuje data, nástroje a specializované asistenty. Nemusí to být jeden obří „superagent“. Naopak je bezpečnější, když má každý agent jasnou roli a omezené oprávnění.

  • Sales Agent pracuje s leady, CRM, nabídkami a follow-upem.
  • Project Agent řeší úkoly, termíny, meetingy a handoff.
  • Knowledge Agent hledá ve firemní dokumentaci a vrací zdroje.
  • Service Agent přijímá požadavky, odpovídá na FAQ a eskaluje výjimky.
  • Reporting Agent skládá přehledy z existujících dat.
  • Voice Agent může zpracovat hovory, zápisy a domlouvání schůzek.

Společný kontext je důležitější než počet agentů

Pokud obchodní agent neví, co slíbil projektový tým, nebo servisní agent nevidí historii zákazníka, vzniká jen další digitální silo. Proto je klíčová firemní paměť a řízené předávání kontextu.

Princip

Agent má vidět právě tolik dat a mít právě tolik oprávnění, kolik potřebuje pro svou roli — ne všechno.

Co musí být vyřešeno před autonomií

  • kdo smí číst která data,
  • kdo smí zapisovat do CRM nebo ERP,
  • které akce musí schválit člověk,
  • jak se loguje, co agent udělal,
  • jak se řeší nejistota a chyba,
  • co se stane, když je externí systém nedostupný.

Proč nezačínat celým Hubem

Nejprve je dobré automatizovat jeden konkrétní proces. Teprve když je ověřený, přidá se druhý. Z několika funkčních workflow pak přirozeně vznikne architektura Hubu. Obrácený postup často vede k drahé platformě, která nemá jasný přínos.

Příklad spolupráce

Nový lead přijde z webu. Sales Agent ho kvalifikuje a zapíše do CRM. Po schůzce Meeting Agent vytvoří zápis a úkoly. Po uzavření zakázky Project Agent založí projekt a termíny. Service Agent později pracuje se stejnou historií. Vedení dostává automatický přehled bez ručního skládání tabulek.

Kdy AI Hub dává největší smysl

Ve firmách, kde informace putují přes několik oddělení a systémů, ale nikdo nemá celý kontext. Právě tam je hodnota orchestrace větší než hodnota dalšího samostatného chatbota.
